    Damaged videos

    Videos players can't jump in (a broken seek index), found by scans. Fix makes a fixed copy (the same video and audio, copied untouched into an indexed file, about as big as the video), which the server then plays in its place. Play each to compare, then replace the original with the fixed copy (as .mkv, keeping its watch progress); the original goes to the trash, where Restore puts it back.

        Background Jobs

        Jobs run at low priority, so playback gets the CPU and disks first. They wait while a disk, network share or mergerfs pool is busy (or, with the setting under Streaming, while anyone is streaming). Pause holds a job until you resume it, or the server restarts.
